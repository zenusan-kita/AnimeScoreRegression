# ANIME SCORE PREDICTION

## Live Demo: 
-> Test the project by visiting the website https://animescoreregression-zenusan.streamlit.app or click [here](https://animescoreregression-zenusan.streamlit.app)

The pipeline is organised into a Jupyter Notebook divided into the following key phases:
1. Data Loading & JSON Parsing
2. Data Cleaning and Feature Engineering
3. Structured Feature Engineering
4. Structured Model (XGBoost Regression)
5. Unstructured Model (NPL)
6. Hybrid Model & Evaluation
7. Deployment

Tech Stack and Libraries 
1. Language: Python 3.12
2. Machine Learning: scikit-learn, XGBoost, SHAP 
3. Data Processing: pandas, numpy, re
4. Visualisation: matplotlib, seaborn
5. Environment: Jupyter Notebook / JupyterLab
6. Deployment: Streamlit Cloud
